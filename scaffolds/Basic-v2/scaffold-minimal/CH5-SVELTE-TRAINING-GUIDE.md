## 🔧 **EXACT IMPLEMENTATION PATTERNS**

### **Signal Connection Patterns - MUST Follow Exactly**

**Digital Signals (Buttons/Triggers):**
```typescript
// Import from ch5-svelte - ONLY source
import { useDigital } from 'ch5-svelte';

// Create signal connection using EXACT contract name
const powerSignal = useDigital('MPC3201B.Power');

// Use in component - ONLY .pulse() for buttons
function handleClick() {
  powerSignal.pulse(); // For momentary button press
}

// Access feedback - NO $ prefix, just .value
$: isActive = powerSignal.value; // Reactive feedback
```

**Analog Signals (Numbers/Levels):**
```typescript
import { useAnalog } from 'ch5-svelte';

// For reading levels (0-65535)
const volumeLevel = useAnalog("MPC3201B.Bargraph");

// For setting values
const sourceControl = useAnalog("MPC3201B.Source");

// Read feedback - NO $ prefix
$: volumePercent = (volumeLevel.value / 65535) * 100;

// Send commands
function selectSource(id: number) {
  sourceControl.setValue(id); // Send specific value
}
```

**Serial Signals (Text/Strings) - Use Direct CrComLib:**
```typescript
// For strings that may change, use direct subscription
let roomName = '';
let roomNameSubscriptionId: string | undefined;

onMount(() => {
  if (window.CrComLib && typeof window.CrComLib.subscribeState === 'function') {
    roomNameSubscriptionId = window.CrComLib.subscribeState(
      's',                    // 's' for string
      'MPC3201B.RoomName',   // Exact contract signal name
      (value: string) => {
        roomName = value || 'Default Name';
      }
    );
    
    // ALWAYS get initial value
    const initialValue = window.CrComLib.getState('s', 'MPC3201B.RoomName');
    roomName = initialValue || 'Default Name';
  }
  
  // MANDATORY cleanup
  return () => {
    if (window.CrComLib && roomNameSubscriptionId) {
      window.CrComLib.unsubscribeState('s', 'MPC3201B.RoomName', roomNameSubscriptionId);
    }
  };
});
```

### **WebXPanel Configuration - MUST be Exact**

**main.ts initialization:**
```typescript
import { mount } from 'svelte';
import App from './App.svelte';
import { getWebXPanel, runsInContainerApp } from '@crestron/ch5-webxpanel';

const initializeWebXPanel = () => {
  try {
    const { isActive, WebXPanel, WebXPanelConfigParams } = getWebXPanel(!runsInContainerApp());
    const config: Partial<typeof WebXPanelConfigParams> = {
      host: "192.168.2.153", // User's control system IP
      ipId: "0x03",          // User's touch panel ID
      roomId: "",            // Usually empty
      authToken: ""          // Usually empty
    };

    if (isActive) {
      WebXPanel.initialize(config);
    }
    
    return true;
  } catch (error) {
    console.error('Failed to initialize WebXPanel:', error);
    return false;
  }
};

// MANDATORY error handling
const initApp = async () => {
  const xpanelInitialized = initializeWebXPanel();
  
  if (!xpanelInitialized) {
    console.warn('WebXPanel initialization failed, continuing in offline mode');
  }

  try {
    const app = mount(App, {
      target: document.getElementById('app')!,
    });
    return app;
  } catch (error) {
    console.error('Failed to mount application:', error);
    document.getElementById('app')!.innerHTML = `
      <div style="padding: 2rem; color: white; background: #0C234B; height: 100vh;">
        <h1>Application Error</h1>
        <p>${error instanceof Error ? error.message : 'An unknown error occurred'}</p>
        <p>Please refresh the page or contact support if the problem persists.</p>
      </div>
    `;
    throw error;
  }
};

initApp().catch(console.error);
```

## ⚠️ **CRITICAL ERROR PATTERNS TO AVOID**

### **❌ NEVER Do This:**
```typescript
// DON'T use $ prefix with ch5-svelte signals
$: volume = $volumeSignal.value; // ERROR: Not a Svelte store

// DON'T create custom signal wrappers  
const myCustomSignal = wrappedUseDigital('signal'); // ERROR: Breaks reactivity

// DON'T use join numbers instead of names
const signal = useDigital('3'); // ERROR: Use contract names

// DON'T skip viteSingleFile plugin
plugins: [svelte()] // ERROR: Won't work on touch panels
```

### **✅ ALWAYS Do This:**
```typescript
// USE direct .value access (no $ prefix)
$: volume = volumeSignal.value; // CORRECT: Direct property access

// USE ch5-svelte library directly
const signal = useDigital('ContractName.SignalName'); // CORRECT

// USE exact contract signal names
const power = useDigital('MPC3201B.Power'); // CORRECT: From contract

// USE viteSingleFile plugin
plugins: [svelte(), viteSingleFile()] // CORRECT: Single file output
```

## 🔍 **TROUBLESHOOTING GUIDE**

### **Black Screen Issues:**
- **Cause**: CrComLib not loading before app
- **Fix**: Verify `<script src="./cr-com-lib.js"></script>` in index.html
- **Cause**: Missing viteSingleFile plugin
- **Fix**: Add `viteSingleFile()` to vite.config.ts plugins array

### **"store_invalid_shape" Error:**
- **Cause**: Using `$signalName.value` syntax
- **Fix**: Change to `signalName.value` (no $ prefix)

### **Signals Not Working:**
- **Cause**: Signal names don't match contract
- **Fix**: Compare signal names exactly with contract.cse2j file
- **Cause**: Contract not loaded on control system
- **Fix**: Verify control system has matching contract loaded

### **Build Fails:**
- **Cause**: Missing required dependencies
- **Fix**: Install exact versions from dependency list above
- **Cause**: Wrong plugin configuration
- **Fix**: Use exact vite.config.ts configuration above
